## Plan

Mỗi bước là 1 todo riêng (file mới trong `wip/`, viết khi tới bước đó), chờ bạn duyệt; code → `npm run typecheck && npm run lint && npm test` → thử trên máy → commit + push. Quảng cáo luôn dùng **ID thử của Google** cho tới bước 11.

- [ ] 1. **Xoá tài khoản:** Edge Function `delete-account` (xoá ảnh `bug-reports/<user_id>/` rồi `auth.admin.deleteUser`; chạy lại được) · test tay trên Supabase local (đủ bảng + ảnh → hết sạch · không token → 401 · A không xoá được B) · app: màn Xoá tài khoản + hộp xác nhận + đang xoá + lỗi (mockup 2–3c) · thu hồi token Google · dọn cache / ảnh nền / thông báo đã hẹn rồi về đăng nhập · Cài đặt: Đăng xuất + Xoá tài khoản xuống cuối · dòng "Chính sách quyền riêng tư" mở URL ([trang đã có](https://danhbuidcn.github.io/daynest-site/privacy/vi.html)) · deploy hàm.
- [ ] 2. **Bản `.aab` đầu cho thử nghiệm kín** (làm sớm để đồng hồ 14 ngày chạy): script build `.aab` ký bằng keystore hiện có · v6.1.0 hoặc bản thử (versionCode 10) chưa có quảng cáo / Pro · bạn tải lên kênh kín (cần tài khoản Play + Google Group — xem "Việc của bạn" trong [todo thiết kế](2026-10-15-s7-design-and-code-plan.md)) · ghi cách đưa bản mới lên kênh.
- [ ] 3. **Nền móng quảng cáo:** thêm `react-native-google-mobile-ads` · plugin trong `app.config.ts` (App ID thử, quyền `AD_ID`) · `features/ads/`: khởi tạo SDK 1 lần, `useAdsEnabled()` (không Pro, chưa trong "tắt 24 giờ", có mạng) · ID quảng cáo gom 1 file (thử ↔ thật theo `__DEV__`) · lỗi tải quảng cáo → không hiện, không báo lỗi.
- [ ] 4. **Pro (RevenueCat):** thêm `react-native-purchases` · `app_user_id` = user id Supabase (đăng xuất → logOut) · entitlement `pro` · `isPro` nhớ trên máy, hỏi lại khi mở / quay lại app · màn **Daynest Pro** (3 gói, mặc định gói năm, đang xử lý, mất mạng, khôi phục, đã mua + quản lý gói trong Google Play) · Cài đặt: nhóm "Tài khoản" + huy hiệu Pro ở thẻ tài khoản · cảnh báo huỷ gói ở màn Xoá tài khoản khi đang Pro · cần **bạn** làm: RevenueCat, 3 sản phẩm Play (chỉ tạo được sau khi có bản `.aab` ở bước 2), gửi public SDK key.
- [ ] 5. **Banner:** `AdBanner` (kiểu anchored adaptive) dưới thanh tab ở mọi màn xem (Lịch, Ghi chú, Todo, Chi tiêu, Cài đặt + màn con chỉ xem) · danh sách màn **cho phép** (không phải danh sách cấm, để màn mới mặc định không có quảng cáo) · không chừa chỗ khi chưa tải · không ở màn soạn / Báo lỗi / Pro / Xoá tài khoản · Pro → ẩn ngay trên mọi tab.
- [ ] 6. **Thẻ quảng cáo gốc:** `NativeAdCard` cùng kiểu thẻ app + nhãn "Quảng cáo" · hàm chọn vị trí (sau mục thứ 4; cuối vùng cuộn cho lưới) · gắn vào Ghi chú, Todo, Lịch (Danh sách + cuối Tháng / Tuần / Ngày), Chi tiêu (Tháng: trước "Theo nhóm"; Ngày / Tuần: sau khoản chi thứ 4) · danh sách ngắn hơn 4 mục → không chèn.
- [ ] 7. **Xem để tắt 24 giờ + UMP:** nút "Xem quảng cáo để tắt 24 giờ" ở màn Pro (quảng cáo có thưởng; hết quảng cáo → hộp thông báo) · lưu giờ hết hạn trên máy, hết hạn thì quảng cáo hiện lại · UMP: hỏi đồng ý lần mở đầu ở EU/UK, chưa đồng ý chưa tải quảng cáo · dòng "Tuỳ chọn quảng cáo" ở Cài đặt chỉ EU/UK.
- [ ] 8. **Chuẩn bị Play (code + tài liệu):** rà lại chính sách quyền riêng tư (thêm quảng cáo, mua trong app, advertising ID; VI + EN) và đẩy lên `daynest-site` · logo thật (thay logo tạm) · kiểm gói Free Supabase ([supabase-plans.md](../docs/specs/architecture/supabase-plans.md)) · soạn nội dung khai Data safety (có dữ liệu sức khoẻ — chu kỳ) / "Có quảng cáo" / `AD_ID` / 18+ · nội dung + video demo cho xác minh OAuth `calendar.events` (bạn nộp).
- [ ] 9. **Thử nghiệm kín:** thay ID thử bằng ID AdMob thật (App ID + banner / native / rewarded — **bạn tạo ở AdMob**; chỉ bật ID thật ở bản `.aab`, máy dev vẫn ID thử) · đưa bản có đủ quảng cáo + Pro lên kênh kín · thử mua bằng tài khoản thử của Play (License testers): mua → tắt trên cả 2 máy · cài lại → khôi phục · sửa lỗi người thử báo · đủ **12 người × 14 ngày liên tục**.
- [ ] 10. **Bản công khai:** khai Play Console (quảng cáo, Data safety, độ tuổi, trang xoá tài khoản) · Apply for production · theo dõi duyệt + xác minh OAuth (có thể vài tuần) · tài khoản ngoài Test users đăng nhập + đồng bộ Google được.
