# personal-hub

App quản lý cá nhân "tất cả trong một": daily note, thể dục, task hằng ngày, chi tiêu, học tập, nhắc nhở. Tùy chỉnh cao. Có bản web và mobile.

## Cấu trúc

| Thư mục | Nội dung | Công nghệ |
| --- | --- | --- |
| `api/` | Backend API | Go, trên nền Supabase (Postgres, Auth, Storage) |
| `web/` | Web app | Nuxt 3 + Nuxt UI |
| `app/` | Mobile app (Android + iOS) | React Native + Expo |
| `docs/` | Tài liệu: tính năng, thiết kế, kế hoạch | — |
| `playbook/` | Skill AI và tài liệu tham khảo cho Claude Code | — |
